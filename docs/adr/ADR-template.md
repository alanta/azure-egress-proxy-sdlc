Use the following template for Architecture Decision Records.

```md

# Title 
## Status
[proposed, accepted, rejected, deprecated, superseded by ..., etc]

## Created / Updated
dd-MMM-yyyy 

## Deciders
[People involved in the decision]

## Work Item [Optional]
[Link to GitHub issue]

## Context
Describe the context and problem statement, e.g., in free form using two to three sentences. You may want to articulate the problem

## Decision drivers [Optional]
List the main considerations for making the decision. For example:

* Operational cost
* Maintainability
* Team knowledge
* Complexity

## Considered options

### Option 1

_Description..._

**Pro:**  
* Reason

**Con:**
* Reason

## Decision
The decision has been made to ... because ...

### Consequences
What becomes easier or more difficult to do because of this change?

### Potential next steps [optional]
Potential next steps?

## Links [optional]
Internal docs, vendor docs, related ADRs etc.

```
